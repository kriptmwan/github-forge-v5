Forge v5: a perf-first, single-file GitHub-compatible git forge in Node 22 (stdlib only). Smart HTTP (git v2/v0, shallow fetch/deepen, thin packs, receive-pack with report-status), REST v3 (repos, issues, pulls, contents), GraphQL v4, and MCP (modern 2026-07-28 discover + legacy initialize) — all backed by one in-memory store with precomputed responses, a fetch-plan pack cache, and single-call pack inflation.
